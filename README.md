# AI Rice Leaf Disease Detection using CNN and Grad-CAM

A deep learning based web application developed for detecting rice leaf diseases using Convolutional Neural Networks (CNN) and Grad-CAM visualization techniques.

## 📌 Project Overview

This project helps farmers and agricultural researchers identify rice leaf diseases from uploaded images. The system predicts the disease type and generates a Grad-CAM heatmap to highlight the affected regions in the leaf image.

---

## 🚀 Features

- Upload rice leaf images
- Disease prediction using CNN model
- Display prediction confidence score
- Grad-CAM visualization for explainability
- User-friendly web interface
- Real-time prediction results
